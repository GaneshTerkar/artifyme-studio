# Artifyme Studio

A premium digital-art discovery experience for Artify, built with the same frontend technology stack as `artify-platform`.

## Stack

- React 18.3 + TypeScript 5.6
- Vite 5.4
- Tailwind CSS 3.4
- React Router 6
- TanStack Query 5
- React Hook Form + Zod

The first delivery focuses on the responsive gallery experience: search, category and attribute filters, sorting, favorites, artwork details, and responsive navigation.

## Development

```bash
npm install
npm run dev
npm run build
```
